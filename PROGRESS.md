## Запуск и проверки

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m backend.init_db
.\.venv\Scripts\python.exe -m backend.seed
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
.\.venv\Scripts\python.exe -m pytest -q
```

Работа по ТЗ завершена. При возобновлении откройте README, проверьте доступность PostgreSQL и выполните команду запуска Uvicorn. Служебные сценарии браузерной проверки находятся в локальной папке `.local-qa`, исключённой из Git.
